Project Overview

A fast-paced Action-RPG built in GameMaker Studio, featuring procedural-style dungeon combat, a deep upgrade system, and a high-intensity bullet hell boss finale.

The Tech

  • Custom State-Machine AI
  • 360° Cursor Aiming & Shooting
  • Stamina-based Dash System
  • Dynamic Boss Phase Logic

The Build

Engine: GameMaker Studio

Language: GML (GameMaker Language)

Art Style: Top-Down Pixel Action
