About the Project

Welcome to the official showcase for my top-down action game built in GameMaker Studio. This project blends tight combat mechanics, RPG-style upgrades, and intense bullet-hell boss encounters into a challenging gauntlet.

Dynamic Combat

Fully 360-degree aiming system with customized weaponry, stamina-based dashing, and precise movement.

RPG Progression

Level up by gathering XP, increase max HP and stamina, and trade for armor and weapon upgrades.

Advanced Boss AI

State-machine driven boss encounters featuring telegraphing, bullet-hell spiral/spread attacks, and environmental interactions.

Created in GameMaker Studio. Hosted on GitHub Pages.
